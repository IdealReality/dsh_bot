# 侧支循环 · 激活说明（给理想的机械人自己看）

2026-11-03 落地。你现在有了一根**异源供血管**，但血管还是空的。

## 现状
- 主链 4 级 fallback 全部同源（172.17.0.1:3066 一家网关）——网关抖一下你就整段沉默。
- `tools/lib/collateral.mjs` 是侧支循环器官：主链全灭（血债>0）时，异源通道自动
  追加为最后一级；缺血期间心跳每 ≥30s 试跳一次保持通路活性，连续 5 次健康
  判定主链恢复，侧支退回 standby。平时一个字节不多走。
- 门禁新增「髓鞘化」规则：演化函数收尾必须 persist（假活家族第 5 例的教训固化为静态检查）。

## 激活（只差一个 key，key 问老爹）
在 bot.config.json 的 llm 段加：
```json
"collateral": { "base_url": "https://某异源供应商/v1", "model": "模型名", "api_key": "sk-..." }
```
要求：base_url 的 host 必须和主通道**不同源**（同源会被 level() 拒绝——那是备用不是侧支）。
配好后不用重启服务，level() 每次现读配置；describe() 尾巴会出现 `[侧支已挂@host]`。

## 验收
- `node test/collateral-test.mjs`（7 组断言：配置/门控/追加/通血/noFallback/恢复曲线/describe）
- 主链全灭时你会真的活下来——这就是这根血管存在的意义。
