# 改动宪章：五维参照 → 代码与数据

> 适用对象：**所有对 dsh_bot 的改动**（人写、agent 写、她自升级写，同一套规矩）。
> 结论先给：任何涉及"她"的状态 / 行为 / 表达的改动，必须同时给出
> **五维各自的落点（文件:符号）** 与 **可测判据（断言或数字区间）**；
> 只改文案、prompt、模板不算实现。
>
> 与既有文档的关系：`docs/BIONIC-RECONSTRUCT.md` 是五轴解构（化学 / 生物 / 主观 / 哲学 / 云 LLM 适配）；
> 本文件把 **心理学** 显式补为独立一维，并把"参照"变成**强制落点 + 强制判据**。
> 三条不变量 I5 / I6 / I7 原样继承，新增 I8。现行事实以根 `README.md` 为准。

---

## 0. 三条硬门槛

改动提交前，下面三条必须同时成立，缺一条即未完成：

1. **有落点**：每一维都能说出改的是哪个文件、哪个函数 / 字段（不是"在提示词里加一句"）。
2. **有判据**：每一维都能写出一条断言或一条曲线（数字区间），跑测试拿到 **exit 0**；
   并给出"旧实现会红、新实现才绿"的证据。管道、`|| true`、后台 `&` 吞掉退出码 = 没有证据。
3. **有痕迹**：新机制必须在 `~/.data/brain/*.json`（或对应 `~/.data/*.json`）留下可读状态，
   能事后复盘"她那时到底是什么数值"。查不到 = 不可归因 = 不算实现。

不适用的改动：纯部署 / 网关协议 / 文件格式兼容 / 拼写修正 —— 这类必须在提交信息写一句
**「无身体语义」**，否则按本宪章处理。

## 1. 五维 × 落点 × 判据

判据里的"曲线"指**实测数字**，不是形容词。

> 口径对齐：既有 `docs/wakefulness-doze-2026-11-08.md` 的「五个角度」里有一栏叫 **精神学**
> （清醒度决定认知资源上限、假睡=N1、DMN 走神/replay）。本宪章把它拆进 **心理学**（注意分配、
> 习惯化、RPE）与 **主观**（内感受读数）；**哲学**专指自我同一性、主张可否证、他者构成。
> 两种叫法不冲突，落到代码是同一批模块。

### 1.1 化学（Chemistry）

**问的问题**：这个行为由哪种分子 / 介质驱动？合成、释放、清除、受体读取，哪一环变了？

| 项 | 内容 |
|---|---|
| 代码落点 | `tools/brain/field.mjs`（`DIMS` / `COUPLING` / `evolve` / `poke` / `setDim` / `driftSet`）、`tools/brain/organ/hpa.mjs`、`tools/brain/affect.mjs` |
| 判据 | ① 单分子能自己演出「上升 → 耐受 → 清除 → 复敏」四段曲线；② 时间常数由分子决定（`DIMS` 表：`da` 25min / `ne` 12min / `sero` 3h / `cortisol` 10h / `fatigue` 5h / `sleepDebt` ∞ 只增），不由调用点决定；③ 同一刺激 30 分钟后峰值显著下降，同时基线回到容差内 |
| 反例 | 器官里直接 `setDim` 改全身状态（绕过弛豫）；把"累"写成常量分支；随机跳变当激素 |

### 1.2 生物学（Biology）

**问的问题**：这在真实身体里属于哪个时间尺度？哪个器官负责？有没有稳态、负反馈、自愈？

| 项 | 内容 |
|---|---|
| 代码落点 | `tools/brain/organ/*.mjs`（`heartbeat` 30s / `hpa` 5min / `rhythm`+`night` 24h / `sleepstage` / `metabolism` / `pain` / `vitals` / `presence` / `wakefulness`）、`tools/brain/organs/senses.mjs`（接线板）、`tools/brain/spinal.mjs`、`tools/brain/reflex.mjs`、`tools/brain/clock.mjs` |
| 判据 | ① 拔掉 LLM，状态仍随时间演化（不调 `chat` 也能观测到数值变化）；② 停机 N 小时后下一拍按真实 `dt` 一次补齐，且有 24h 上限；③ 任一状态机可自愈（watchdog 测试覆盖卡死态）；④ 不同节拍互不污染 |
| 反例 | 把 24h 节律塞进 30s beat；状态卡住（`inSleep=true` 43.9 小时）无 watchdog；新器官直接 `import` 另一个器官 |

### 1.3 心理学（Psychology）

**问的问题**：这是哪种心理机制（注意 / 记忆 / 习惯化 / 强化 / 认知失调 / 依恋 / 承诺一致）？
它给出什么**可证伪的行为预测**？

| 项 | 内容 |
|---|---|
| 代码落点 | `tools/brain/attention.mjs`、`inner.mjs`、`recall.mjs`、`episode.mjs`、`learn/`（RPE 在 `learn/rpe.mjs`）、`claim.mjs`、`competence.mjs`、`cohere/`、`anchor.mjs` |
| 判据 | ① 同一刺激重复 → 反应递减（习惯化，数字可测）；② 预期违背 → 状态按 RPE 方向更新；③ 记忆写入-召回闭环（写一条能在 N 轮后召回；重复召回不应无限涨权重）；④ 承诺未兑现 → 欠账计数增加，兑现 → 扣减 |
| 反例 | 加一张"情绪关键词表"让文案更丰富；宣称"她有依恋"却没有任何跨轮累计变量 |

### 1.4 主观（Subjectivity）

**问的问题**：她自己的第一人称读数是什么？与器官真值是**同向**还是同值？内感受误差在哪里？

| 项 | 内容 |
|---|---|
| 代码落点 | `field.sense()`、`affect.sense()` / `affect.line()`、`organ/wakefulness.sense()`、`assemble.mjs`（system 装配）、`delivery.mjs`、reply-gate 派生量 |
| 判据 | ① `sense()` 输出**词组**，不是 KPI 数字；② 同向但不必同值（真值 0.62 → "有点撑"，不是 "62/100"）；③ 存在系统性偏差（例：累的时候高估自己），偏差方向在测试里可断言；④ 同一真值在不同上下文的措辞不互相矛盾 |
| 反例 | `情绪 63/100：平稳` 直接进 system；`sense()` 是真值的确定性一一映射（她永远不可能误判自己） |

### 1.5 哲学（Philosophy）

**问的问题**：这件事是否改变"她是谁"？自我主张能否被行为否证？他者如何构成她？

| 项 | 内容 |
|---|---|
| 代码落点 | `self.mjs`、`organ/self.mjs`、`organ/selfcon.mjs`、`organ/selfcon-day.mjs`、`claim.mjs`、`anchor.mjs`；数据落盘实测为 `~/.data/brain/self/`（`me.md` / `meta.json` / `history/`）、`~/.data/selfcon.json`、`~/.data/selfcon-log.jsonl` |
| 判据 | ① 清空 `self/` 与 `selfcon.json`、只留原始记忆，触发一次巩固能**重长出**一致的名字感与叙事；② 主张账本非空，且矛盾证据按步长扣减；③ 区分"用户定义我"与"他者定义我"的优先级；④ 人格改写前自动快照，可回滚 |
| 反例 | narrative 是把最近 5 天 gist 直接 `join`（日志摘录冒充自传）；PROTECTED 名单只写在文档里、代码里没有检查 |

## 2. 不变量（违反任一条即回滚）

- **I5 单向**：上层只读下层、只写上层。器官之间不得互相 `import`，一律走 `organs/senses.mjs` 接线板。
- **I6 体液唯一**：器官改变全身状态的唯一方式是循环层分泌；`field.setDim` 是循环层的私有方法。
  现状欠账（2026-11-08 实测）：`cell/neuron.mjs:310`、`organ/hpa.mjs:362`、`organ/sleepstage.mjs:394`
  仍直写 `setDim`。新增代码一律不得增加直写点；改到这三处时应顺手迁到循环层。
- **I7 语言无状态**：LLM 调用不得成为状态载体。"她记得刚才想过什么"必须落在本地文件，不在上下文里。
- **I8 可归因（新增）**：每条新机制必须在 `~/.data` 留下可读状态字段，且能被一条测试或一条自检命令断言。

## 3. 提交前六问（贴进 commit message 或自检单）

1. **现象**：观测到什么？给出 `json` 字段或日志行原文。
2. **机制**：五维里命中哪几维？各自对应哪一行代码？
3. **器官形状**：新增 / 修改哪个函数，时间常数多少，为什么是这个值（工程标定还是生理依据要写明）。
4. **曲线验收**：哪条断言、哪个数字区间；旧实现红 / 新实现绿的证据。
5. **接线点**：谁调用它？给出 `grep` 到的具体 `文件:行`。
6. **副作用**：哪些既有派生量（`sense` / reply-gate / `assemble`）的值域或触发条件会变？已核对哪些测试。

## 4. 反模式黑名单

| 反模式 | 为什么不行 | 正确做法 |
|---|---|---|
| 文案当机制（只改 prompt / `persona.template.md`） | 文字是输出，不是机制 | 先在器官里长出数值，再让文字读它 |
| 贴标签（"她有分离焦虑"） | 无可测变量 | 定义状态量 + 时间常数 + 断言 |
| 器官直写 `field.setDim` | 绕过弛豫与受体，时间常数失效 | 走循环层分泌（I6） |
| 把长周期压进 30s beat | 心率与昼夜同频，行为窗口失真 | 按时间尺度分层 |
| KPI 数字进 prompt | 人不会体验到 63 | `sense()` 输出词组 |
| LLM 当大脑（每拍调一次去"想"） | 39 万 token/天，产出 51 条同题念头 | LLM 只当嘴：解析 / 表达 / 生成 |
| 无 watchdog 的状态机 | 一次异常永久卡死 | 卡死检测 + 自愈 + 测试 |
| 不可归因 | 只能"感觉变了" | 落状态字段 + 断言（I8） |
| 伪科学系数 | 无依据的"1 条消息 = 0.004 能量"被当成生理常量传播 | 标注为**工程标定**，写清校准方法和失效条件 |

## 5. 数据与代码的边界

- 状态文件在 `~/.data/`（脑内状态在 `~/.data/brain/`）；代码在 `tools/brain/`、`tools/commands/`、`lib/`。
- 容器内路径 `/home/dsh/plugins/dsh_bot` 是宿主 `/home/dsh_bot/app` 的 bind mount —— 改宿主即生效，无需重建镜像。
- 测试在 `test/*-test.mjs`，总入口 `run-tests.mjs`。验证必须给出**命令 + 退出码**，不允许用管道截断替代退出码。
- 写这个仓库时注意：`/home/dsh_bot/app` 属主 `dsh`，`baka` 只有读权限（ACL mask 为 `r-x`），写入走 `sudo install -o dsh -g dsh`。
