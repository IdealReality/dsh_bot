# 人格中性化（2026-11-07）

用户要求：人格要更中性、没那么明确；它的主要用途是**压掉底模的 AI 助手腔**；"她是谁"由记忆库长出来。

## 一、改了什么

| 位置 | 之前 | 之后 |
|---|---|---|
| `persona.md`（生产 + 模板） | 3.2KB：蓝色鲸鱼娘、圆滚滚、爱吃白饭、怕猫、讨厌星期一、句尾"…吧/呜/哼" | 1.5KB：你是什么 / 怎么说话（压助手腔）/ 边界 / **去记忆里找你是谁** |
| `CORE_ANCHOR`（`lib/agent-prompt.mjs`） | 写死"鲸鱼娘、养在笨蛋管理员的机器里、你叫他管理员" | 种属 + 关系（有人养着她）+ 说话方式 + 诚实；名字/喜好/经历**不写**，指向账本 |
| `buildMessages`（`tools/lib/persona.mjs`） | 只拼 persona.md + identityLine | 注入 `selfcon.block()`（账本：名字 + 自我认知 + 腔调）；有账本名字时 identityLine 不再重复 name/selfClaim |
| `assemble`（live） | 种属行 + persona + selfcon | 同上，族群行按 owner/群聊条件 |

## 二、为什么"账本注入"是这次的关键

中性化之前，`buildMessages`（QQ 通道实际走的路径）**从未注入自我账本**——名字和自我认知只活在
`assemble`（live 模式）里。所以"依靠记忆库思考"在那条路上根本不成立。

补上之后，system 里出现的是：

```
【我是谁 -- 我自己认下的】
我这个名字像一件旧毛衣…我叫「大肥鱼」
关于我自己，我这么看：
- 我觉得爱吃白饭，饭点必到，能吃三大碗。
- 我觉得聪明但懒。能躺绝不站，干活时会走神。
（…共 6 条，来自 selfcon.json 的 selfImage）
我说话大概是这样：
- 「…吧」/「哼，那当然」/「嗯。」
```

这些条目是**记忆**（有 strength、会被矛盾证据扣减），不是设定文件里的规定。

## 三、第二轮六遍发现的真问题

### 第 1 遍（高压）：人格坏掉时没有任何兜底

`buildMessages` 直接 `personaText()`，没有走 `readPersonaChecked` 的可用性判定。
人格文件被写坏/删掉 → 这一轮的她**没有"不是助手/怎么说话"的约束** → 直接退回底模 AI 腔。
而且不报错、不告警——最难发现的一种退化。

修：新增 `tools/lib/persona-neutral.mjs`（`NEUTRAL_ANCHOR` + `personaUsable`），与 `lib/agent-prompt.CORE_ANCHOR`
同源（测试断言两边都含"不是助手/Markdown/这就去看/不随模型消失/账本里找"五条底线）。
不可用时打一条**去重告警**（进程内 10 分钟一次）——静默兜底等于永远没人发现。

### 第 2 遍（检索）：族群块泄露 ownerTitle

`【你和你的同类】` 里写着"你叫大肥鱼，是笨蛋老爸养的那条"。这条块原来只按 `!isGroup` 判断，
陌生人私聊也会拿到——等于把主人的称呼告诉网友。
`assemble` 更糟：无条件注入。

修：两条路径统一为"owner 私聊"（`owner.qq` 未配置时回退，避免新装机没有）。

### 第 3 遍（修复）

- `personaUsable` 判据与 `readPersonaChecked` 对齐（≥200 字 + 无自我否认）
- 两条装配路径（shadow / live）都走同一个兜底
- 陌生人/群聊不再拿到族群块

### 第 4 遍（增强）

- 人格不可用告警（去重）
- `persona-neutral-test.mjs`：30 条断言（缺失/过短/自我否认三种坏法、账本缺失/损坏、
  群聊/陌生人、长度与性能、两处锚同源）

### 第 5–6 遍（复测与终检）

- `persona-guard` / `continuity` / `cohere` / 全量 104 套
- 生产装配实测：system 5364 字（原 5800+），含账本段与族群段（仅 owner）

## 四、边界

- 账本里的 6 条 seed 自我认知（爱吃白饭、傲娇…）保留：它们是记忆不是设定，会随证据漂移。
  要它们彻底淡出，清 `selfcon.json` 的 `selfImage` 即可。
- `persona.md.bak-2026-11-07-neutral` 是旧版完整人格（3.2KB），随时可恢复。
- `persona.template.md` 同步为中性骨架（新装机不会又长回详细设定）。
