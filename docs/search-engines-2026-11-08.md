# 大肥鱼 · 搜索换引擎层（2026-11-08）

> 用户看到的现象：**"大肥鱼似乎搜不了东西"** —— 她说「搜"菠萝包"全是水果」，把没搜到说成搜到了别的东西。
> 结论：不是"没网"，是**把脏数据当成了搜索结果**。查询层（引擎）从来没有被检验过相关性，
> 只在"结果长度 = 0"时才换引擎，于是"有结果但全不对题"永远拦不住。

---

## 一、根因（实测，不是推断）

同一台生产容器 `dsh_bot`，2026-11-08 19:27 起逐条对照（`docker exec … node /tmp/probe*.mjs`）：

| query | cn.bing.com（原唯一引擎） | www.so.com（360） |
|---|---|---|
| `费曼 趣事 科学顽童 故事` | 全是 **"费（汉语文字）_百度百科"** —— 只按首词"费"出结果 | 「科学顽童费曼的故事」「别闹了,费曼先生:科学顽童的故事」 |
| `醒来后脑子发懵 多久能恢复 早晨 认知` | 全是 **《醒来》那部谍战剧** | 「意识朦胧状态多久能苏醒」等相关页 |
| `电池 保养 注意事项` | 全是 **"电池（把化学能转化成电能的装置）"** | 「电池的日常维护要点」「电池保养过程中要注意哪些细节」 |

- **bing 的 cn 接口对多词中文 query 会退化成首词**（去掉 `format=rss` 走 HTML 版、加 `mkt=zh-CN` 也一样，
  两版结果字符串完全同构），单看 HTTP 是 200、`<item>` 有 10 条 —— 所以原链路认为"搜到了"。
- **原链路只判长度**：`if (!results.length)` 才换 DDG；容器里没有 curl，DDG 又必然失败 →
  等于**全世界只剩 bing 一个引擎**，脏数据一条不落地全灌到她眼前。
- 顺带查到的历史账（`~/.data/web-log.md` 61 次搜索）：11-08 下午之前 **60 次记成"0 条结果"**。
  其中最可能的一层是长驻进程里 undici 复用被对端关掉的闲置 socket（`lib/fetch-bytes.mjs` 里记过同一现象），
  旧代码 `swallow()` 把这个错吞掉，日志只留下"0 条"。

## 二、改了什么

1. **新增 `tools/lib/search-engines.mjs`（引擎层）**
   - 三家**并发**：360（`data-mdurl` 取真实地址，外层 `so.com/link?...` 是跳转壳，不能用）→ bing RSS → DDG（要代理）。
   - **相关性打分**：query 分词（含连写整体），逐词在 标题+摘要+URL 里找覆盖度；
     长词（≥4 字）允许二元组部分命中（`醒来后脑子发懵` ⇄ `意识朦胧…苏醒`），短词必须整体命中
     —— 否则 bing 的"首词退化"又会混进来。及格线 `RELEVANT = 0.34`。
   - **全脏才算没搜到**：低分结果直接丢弃，`weak: true` 往外走，**不许**把脏数据当答案。
   - **全脏时换短写法再搜一次**（去噪声词 / 只留前两个词 / 整串连写，最多两个变体），
     变体结果按变体自身打分 ×0.9。
   - 编排在 `tools/commands/web.mjs`：`searchWeb()` 改用它；`web search` 在 0 条时输出
     "没搜到对题的结果 …… 要么换个更具体的说法，要么直说不知道，别拿不相关的东西凑答案"。
   - `searchSmart()` 的浏览器兜底 SERP 从 bing 换成 360，**并且也要过相关性关**。
2. **`look_up` 的结果交代用法**（`tools/lib/tools.mjs`）：带上"挑 1~2 条最对题的，把标题和站点名说给他；
   要看正文用 `browse_page`"。截断上限 1800 → 2400 字。
3. **`httpGet` fetch 失败重试一次**（坏 keep-alive socket），400/超时不重试。
4. **测试** `test/search-engines-test.mjs`（35 条，不联网）已注册进 `tools/run-tests.mjs`：
   盯 360 的 `data-mdurl`、bing 首词退化必须判 0 分、变体重试上限、单引擎挂掉不拖垮整链、全挂不抛。

## 三、上线后实测（生产容器）

```
node bot.mjs web search "费曼 趣事 科学顽童 故事"
  → 4 条：喜马拉雅《别闹了,费曼先生:科学顽童的故事》/ 图书馆书目 / 豆瓣《科学顽童:费曼》

node bot.mjs web search "菠萝包 轻小说"
  → 5 条：第 1 条 SF轻小说（菠萝包轻小说官网）、应用宝、mergeek、华军…

node bot.mjs web search "醒来后脑子发懵 多久能恢复 早晨 认知"
  → 没搜到对题的结果（引擎给的确实全是昏迷/脑震荡页）—— 如实说没搜到，不糊弄

换说法 "早上醒来脑子不清醒 原因"
  → 2 条：复禾健康「每天早上脑袋不清醒怎么回事」/ 家庭医生在线
```

工具路径（模型真正走的 `look_up`）也验过：`runTool('look_up', {mode:'search', q:'菠萝包 轻小说'})`
返回 956 字、末行带用法提示。

## 四、还没做的

- **过时日志里的 60 次"0 条"**没有逐条复现（那时段的日志只剩长度），重试 + 多引擎是针对性兜底，
  不是"已证实的唯一原因"。若还出现成片的 0 条，先看 `~/.data/web-log.md` 的 `搜索失败` 行 —— 现在会写明是哪个引擎、什么错。
- 360 的 `data-mdurl` 是它自己标的落地页，偶有站点首页替身（如 `boatescrump.com`），
  这类"内容农场"只能靠相关性 + 她自己的判断过滤，没有做黑名单。
