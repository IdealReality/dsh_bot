## 三、五轴设计（`tools/brain/learn/`）

```
        ┌──────────── 精神层：策略 = 心理姿势，不是梗 ────────────┐
        │ 幽默 / 升华 / 利他 / 压抑 / 合理化 / 回避                │
        └───────────────▲───────────────────────────────────────┘
  哲学层：fits（"这像我吗"）—— 有效但不像我的说法，权重再高也不采纳
        ┌───────────────▲───────────────────────────────────────┐
  生物学层：场景先验（他在逗 / 给了任务 / 在挑错）—— 进化给的本能，不用学
        ┌───────────────▲───────────────────────────────────────┐
  化学层：RPE（实际 − 预期）驱动权重；受体敏感度衰减 = 耐受
        ┌───────────────▲───────────────────────────────────────┐
  主观层：奖励来自"他下一条消息给人的感觉"，不是打点
```

### 化学层 `rpe.mjs`

- `reward = 0.45·情绪价 + 0.20·是否继续 + 0.35·明说（夸/骂）`
- `rpe = reward − 该策略的历史均值`；`w += α·rpe·敏感度`
- `sens` 每用一次 ×0.97（下限 0.35），18 小时恢复约 63%
- **耐受是真的**：同样奖励第 8 次的增量只有第 1 次的 1/3（实测 0.084 → 0.027）

### 生物学层 `strategies.mjs`

- `baseScores()`：被逗→幽默 +3、给了他任务→升华 +3、被挑错→合理化 +3.5、压力大没耐心→回避 +2.5
- 先验是**打分**而不是 if 链 —— 否则学习和先验没法相加

### 哲学层：`fits`

| 策略 | fits | 含义 |
|---|---|---|
| 幽默 / 利他 | 1.00 | 这就是她 |
| 升华 | 0.95 | |
| 压抑 | 0.85 | |
| 合理化 | 0.80 | |
| 回避 | 0.55 | 能不用就不用 |

回避哪怕被训练到最高权重，`0.95 × 0.55` 也压不过幽默的 `0.5 × 1.0` —— 不是道德判断，是"这不像我"。

### 主观层：奖励来源

不是打点，是**他的下一条消息**：情绪价（`percept.emoji.valence`）、是否继续这一段、有没有明说。

### 精神层：资格迹

`recordUsed()` 在"真发出去"时记下"这轮用了哪种姿势"；他的下一条来了（30 分钟内、同一会话）才结算。跨会话、隔太久都不归因 —— 无法归因的反馈不如不要。

## 四、可读语料（黑话的只读版）`lexicon`

- 从入站消息里抽 2~4 字中文块，剥词尾语气词（"摸鱼了"→"摸鱼"），去停用词
- ≥4 次且 7 天内 → 以一行注入：「他这些天常说的词：…（听得懂就自然接，别为了显得懂而硬用）」
- **只学理解，不主动用**：现学现卖是最像机器人的行为之一
- 按会话隔离，有界 200 词/会话

## 五、实测

闭环（容器内实跑，`qq:learn-probe`）：

```
第一轮 策略 = sublimation | percept = REQUEST
记资格迹后： {"name":"sublimation","w":0.5,"mean":0,"sens":0.97,"n":1}
结算后：     {"name":"sublimation","w":0.52,"mean":0.026,"sens":0.97,"n":2}
stats = {"turns":1,"updates":1,"rewardSum":0.175}
lexicon = {"chats":1,"words":3}
```

顺带修掉一个**影响所有情绪判断**的缺陷：
`TONE.neg` 里的单字「靠」把「太靠谱了」判成负面 —— 奖励直接从 +0.5 变成 −0.5。
现在单字脏话改成组合（我靠/靠北/我操/卧槽/好累/累死/好烦/烦死…），宁可漏判，不把夸奖当批评。

修正前后（同一句）：

| 输入 | 旧 reward | 新 reward |
|---|---|---|
| 谢谢，太靠谱了 | 0.175（valence 被误判 −0.5） | **0.550** |
| 你怎么这样啊 | 0.050（被骂还算正反馈） | **−0.150** |

## 六、不做的事（明确）

- 不做"黑话生成"：学会一个词就往回复里塞，是群聊机器人最典型的假。
- 不做自训 9B：硬件不允许，且同类方案实测 90s/回复。
- 不做审查 UI：学习结果只有权重，没有"人格文本"要批；要回滚删 `brain/learn/*.json` 即可。

## 八、第二轮六遍（高压 → 修复）

新增的学习器官在第一轮里只做了正常路径。紧接着跑了六遍高压/修缮，找到四个真缺陷：

### 第一遍：高压测试（新脚本 `test/learn-stress-test.mjs`）

| 注入 | 结果 | 判定 |
|---|---|---|
| `pick(null)` | 抛 `Cannot read properties of null (reading 'base')` | 修 |
| `reinforce(arm, NaN)` | `w`/`mean` 写成 `null`（JSON 里 NaN→null），该策略**永久坏掉** | 修 |
| 8 进程 × 25 轮并发 `recordUsed` | `n=5`（期望 ≥200，丢失 97%） | 修 |
| 时钟回拨 / 29 与 31 分钟边界 / 10000 小时恢复 | 正常 | — |
| 目录只读 | 不抛、数据不坏 | — |
| `pick ×200` / `observe ×100` | 26ms / 404ms | — |

### 第二遍：全链路检索

- 每轮 IO：`perceive` 写 strategies + lexicon；`frame` 读 strategies + lexicon；`after` 写 strategies ≈ 5 次。实测 4ms/次，可接受。
- **规则双写**：`psyche.chooseDefense` 的 if 链与 `learn.baseScores` 各写一套先验 —— 改一处漏一处时，"静态选择"和"学习先验"会悄悄漂移（现象：学几天后同一句话接法突然变了）。改为 psyche 直接调用 `baseScores`（learn 不 import psyche，无环）。

### 第三遍：修复

| 问题 | 修法 |
|---|---|
| 并发丢更新 97% | `recordUsed` / `observeIncoming` 改为 **mutateJson 单事务**（load 移进锁内）。并发后 `n=377`（上限 400） |
| NaN 污染 | `reinforce` 先校验 `Number.isFinite`，非有限值直接"这次没有信息"；`rewardOf` 同样钳住 valence |
| `pick(null)` | `o = o || {}` |
| 先验双写 | psyche 复用 `baseScores` |
| 群聊称呼 | 语料提示按 `isGroup` 说「群里」而不是「他」 |

### 第四遍：增强（可见性）

- `node bot.mjs brain learn` → 六种姿势的 `w/mean/sens/n`、语料规模
- 每轮结算打一行：`🎓 上次「sublimation」reward 0.55 rpe 0.524`（实测日志）

### 第五遍：复测

`learn-test`（24 断言）/ `learn-stress-test`（16 断言）/ `cohere-test` 三套全绿；容器内复跑 stress 全绿。

### 第六遍：终检

- 新增 `learn-stress-test` 注册进 `tools/run-tests.mjs`
- 全量套数 102 → **104**（+learn +learn-stress）
- 生产重启后 `brain learn` 与 🎓 日志实测可用

### 已知残留

- 并发 8 进程仍有约 5% 丢失：`mutateJson` 在锁争用超时后会**放弃写入**（fail-closed，不裸写）。这是刻意的取舍——宁可丢一次学习更新，也不要覆盖别人的状态。真实路径里只有 qq-server 单进程写，不触发。
