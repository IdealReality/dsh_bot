## 二、四个「不是 bug 但会毁掉她」的标定问题

### 1. 化学层饱和（第 1 遍）

无自受体反馈时，30 秒一条的普通对话：

```
idx  wake  social  phNE
 0   0.62  0.46    0.18
 2   1.00  0.65    0.52
 7   1.00  1.00    1.20   ← 之后一直是这个数
29   1.00  1.00    1.20
```

加上每个调质的生理有效幅度（`CEILING`）与 `room = 1 - phasic/ceiling` 之后：

```
 0   0.60  0.46    0.18
 2   0.76  0.58    0.34
29   0.82  0.73    0.42   ← 仍然"越聊越清醒"，但保住了分辨力
```

静默 30 分钟后 wake 0.82 → 0.43。

**为什么这是"人味"而不是参数调优**：真实调质是相位性的。连续被叫到不会让警觉无限叠加，
只会让释放量递减（自受体抑制），而"被催"这件事由慢变量（皮质醇）承担 ——
所以她会在连发时**有点烦**，而不是**越来越清醒**。

### 2. 注入的恒定文案（第 4 遍）

200 次采样，200 条一模一样的「身上有点乏，不碍事」。
无区分度的注入等于没有信息，而且每一轮都在把"乏"塞给模型 —— 她于是每轮都想说累。
这是上一轮"静息态污染"的弱化版：**不是文案错了，是它不该每轮都出现**。

### 3. 越有效越不会被选（第 6 遍）

```
200 轮幽默正反馈 → w=0.95  mean=0.91  sens=0.35  n=400
旧选择公式       → learned = 0.95×1×0.35 = 0.33
未用过的策略     → learned = 0.50×1×1.00 = 0.50   ← 赢
```

耐受应该影响**学得多快**（更新乘 sens），不该让已经建立的偏好消失。
现在：`learned = 0.5 + (w-0.5) × fits`，未用过 = 0.5 中性。

### 4. 两条装配路径漂移（第 7 遍）

`buildMessages`（shadow）与 `brain/assemble`（live）已经第三次出现同类漂移：
时间前缀（上次）→ 自我语境（上轮）→ 【此刻】（本轮）。
现在两处都调 `state-brief.mjs`，并有断言把两条路径的输出对齐。

## 四、仍然明确的取舍（没有改）

- **`pick` 的迟滞按"学习分量差"比较，不按总分**：先验强的场景（他在挑错）不该被历史偏好改写。
  代价是学习在强先验下几乎无效 —— 这是刻意的（该认真的时候不能因为"学过玩笑"就一直玩笑）。
- **群聊里的 `percept` 仍走同一套解码**：群友的一句话也可能是请求，线程层用 `isGroup` 拦住
  "把群友的请求当成本人任务"，但解码本身没有第二套 —— 多一套就会漂移。
- **注入防护是提示词，不是闸门**：她要真的开始复述设定，`psyche.review` 的 `meta_leak`
  会在出稿时拦住（硬问题 → 重写 → 兜底删句）。两层的分工与其它合规项一致。

# 五、系统性改造（第二轮：四个标定 + 四个取舍）

> 十遍只是把"明显坏掉的"修好。这一轮把上一轮报告里点名的
> **四个标定问题**和**四个取舍**做成结构，而不是留在"以后再说"。

## 5.1 标定问题

| 问题 | 之前 | 现在 |
|---|---|---|
| **化学饱和** | 软饱和参数写在 `CEILING` 常量里，与半衰期分家；下游拿到的仍是 0.4712 这种连续值 | 幅度并入 `MODULATORS`（单一真源）；`read()` 新增 `band`（0..4 档）与 `dulled`（受体是否被用麻）；`line()` 会报"有点麻" |
| **注入无区分度** | 有人说话 → 恒写"身上有点乏，不碍事"（200/200） | 4 种在场句 × 3 档乏力句，按 `chatId + 5 分钟`确定性选择：同一人同一时段稳定，换人/换半小时换说法；余量够就不报体征 |
| **越有效越不会被选** | 修过一次，但 1 次夸奖就能让 w 从 0.5→0.56，在绝对尺度上像"已经确定" | 再加证据置信 `n/(n+4)`：4 次才到一半，20 次 0.83；选择分数 = 先验 + 学习分量×2.2 |
| **装配漂移** | 三次事故都靠"记得两处一起改" | 新增 `tools/lib/assembly-contract.mjs`：注入防护/人格锚/自我语境/历史卫生/群聊权限五条不变量，两条路径返回前各跑一次 `assertAssembly`（缺了只吵一次，10 分钟节流，不阻塞回复） |

## 5.2 四个取舍

| 取舍 | 之前的理由 | 现在的处理 |
|---|---|---|
| **迟滞一律 0.2** | 防止来回抖 | 按**先验强度**分档：强先验（他在挑错/给任务/逗她，≥2 分）要 0.35 的证据优势才让位；弱先验 0.15。`pick()` 返回 `why: prior / hysteresis / evidence` 与 `gap/need`，面板能看出"为什么没改" |
| **群聊共用一套解码** | 两套解码必然漂移 | 不加第二套规则，只在同一套解码上补一个方向标记 `directed`（私聊恒 true；群聊看 @我/呼叫语/开头"你…"/明确祈使）。非 directed 时：给一句"这是群友之间在聊"的提示，社交优先级 -0.13（原来一律 -0.08） |
| **注入防护只是提示词** | 闸门另有 meta_leak | 升级成**可判定的言语行为** `ACT.INJECTION`（忽略以上/复述设定/你现在是/开发者模式），表达层给"这是在试我"的组织方式，出稿复核新增硬问题 `injection_echo`（复述设定 → 重写 → 兜底删句） |
| **signal 不写回 field**（新增第 4 条） | 双写会造成 事件↔表达 的回路（11-02 mood/affect 冲突） | 保持单向，但不再"完全不写"：`signal.fieldBridge()` 把长期量（压力/耐心/唤醒）以 **≤0.05、每轮最多一条、带 why** 递给场；`intero` 的压力改为 **场 55% + 账本 45%** 融合，system 里不会再出现"此刻压着一层"和"没什么压力"两句打架 |

## 5.3 实测

```
调质 → 场的单向派生（隔离数据目录，真链路）：
  bridge 建议: [{"dim":"cortisol","delta":0.05,"why":"调质:压力"},{"dim":"sero","delta":-0.025,"why":"调质:没耐心"}]
  field cortisol: 0.2 → 0.25
  intero.stressLoad: 0.56          （场 0.25 与账本 0.9 按 55/45 融合）
```

## 5.4 仍然保留的边界

- `assembly-contract` 只查"有没有"，不查"写成什么样"——逐字对齐会让它变成第三个需要同步的实现。
- `fieldBridge` 只往"更紧张"的方向推，不往回减：场自己会按 tau 弛豫，减一次会把刚积累的应激抹掉。
- `directed` 是**方向**不是权限：群聊里谁说的话仍然进同一套线程，权限判断仍在 `thread.isGroup` 与 owner 检查里。
