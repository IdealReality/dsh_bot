## 二、根因（每条都有实测证据）

| # | 根因 | 证据 |
|---|---|---|
| 1 | **"上次断在哪"每轮都拼到最后一条 user 消息上** | 用户只说 17 字「看看你有多少余额」，装配出的 user 消息 303 字，其中 250 字是"你们之前聊过 / 上次断在哪"；指令还写着"接着上次的话头往下说" |
| 2 | **时间前缀进了记忆，又被二次叠加** | 历史行 `[19 分钟前] [刚刚] 就一个笑的表情…`；模型随后学会自己输出 `[刚刚]` |
| 3 | **静息态被当成对话态度** | system `【此刻】我啥都不太想干，就想窝着发会儿呆，脑子实在转不动` → 回复「别让我猜」「我躺着犯困」 |
| 4 | **内省层允许"不想理就敷衍"** | `think.mjs` 的内省提示词："如果你其实不太想理他…就照实写出来"；speak："不想理就敷衍一句" |
| 5 | **没有"这句话在干什么"的解码层** | 所有输入都落到同一句"他刚说了话"，意图交给 LLM 现猜；猜不到就问 |
| 6 | **线程状态只记最后一条** | `brain/working`：`topic = "用户：😋"`、`recallA = "刚说的：😋"` |
| 7 | **视频抽帧从未执行** | qq-server 调 `sampleVideoFrames(...)`，该函数全仓没有定义/导入 → 每次 ReferenceError 被 catch 吞掉 |

## 三、器官（五层 + 表达）

```
                  ┌──────────── 表达层 expression ────────────┐
                  │ 结构：接住 → 实质/动作 → 至多一个话头        │
                  │ 出站清洗：时间标注 / 说话人标签 / 空行     │
                  └───────────────▲──────────────────────────┘
   精神层 psyche ── 防御机制 / 社交抑制 / 元认知复核（硬问题才重写）
                  ┌───────────────▲──────────────────────────┐
   哲学层 thread ── 线程：在说什么 / 他要什么 / 我问过什么 / 答应了什么
                  ┌───────────────▲──────────────────────────┐
   主观层 intero ── 余量 / 社交优先 vs 静息 / 允许误读自己
                  ┌───────────────▲──────────────────────────┐
   生物层 percept ─ 感受器：言语行为 / 表情语气 / 指代 / 连续性
                  ┌───────────────▲──────────────────────────┐
   化学层 signal ── 七种调质：DA/NE/5-HT/ACh/OT/GABA/Cortisol
```

### 1. 化学层 `signal.mjs`

- 七种调质，各带基线、半衰期、负荷与受体敏感度（耐受）。
- **社会在场反射**：他一开口 → NE +0.18、ACh +0.22、OT +0.08。
  这是修根因 3 的物理手段：不是用提示词求她"热情一点"，而是先让警觉真的抬起来。
- 一句话的后果按言语行为施加：请求→ACh/DA；批评→皮质醇/血清素↓；逗→DA/OT。
- 只读不写 field：避免"事件 → field → 表达 → 事件"的双写回路（mood/affect 双源冲突的老病）。

### 2. 生物层 `percept.mjs`

- 言语行为：REQUEST / COMMAND / CRITIQUE / REPAIR / SHARE / TEASE / QUESTION / ACK / EMOTE / CLOSING / TOPIC。
- 关键判定：
  - `不是，是…` → REPAIR（不是骂人），并抽出**新动作**（`去嘲讽 …视频`）。
  - `看看你有多少余额` → QUESTION（数词疑问），不是 REQUEST。
  - `别去管别人怎么运营` → 不是问句（中文的"怎么"大量出现在陈述里）。
  - 纯 emoji → EMOTE + 情绪坐标；不是"没说话"。
- 连续性：<90s = same_beat；<10min = continuing；<40min = reopen；否则 new_session。
- 全部确定性规则，零 LLM：主链路延迟 0.02ms/次（实测 decode ×50 = 0.9ms）。

### 3. 哲学层 `thread.mjs`

- 每会话一个状态：`topic / goal / open questions / myQuestions / commitments / moves`。
- 目标（意向性）：REQUEST/COMMAND/REPAIR 覆盖；换话题且没有新任务时清空。
- `frame()` 只给**指针**（不给摘要）：
  ```
  · 在说：大肥鱼自运营的视频
  · 他要我做的：去嘲讽「…视频」
  · 我已经问回去过：「你是说…」（同一件事不许再问第二遍）
  ```
- 复核（纯读 `inspect`，写盘 `after` 分开）：`dodge`（答非所问）、`repeat_question`、`self_absorption`、`scold`、`time_prefix`。

### 4. 主观层 `intero.mjs`

- 读数仍来自 `field`（8 维场），这里只做**仲裁**：`socialPriority` vs `restPriority`。
- 结论只能改语气，不能取消"接住"：`mustAcknowledge = !!percept`，没有参数能关掉。
- 允许误读：累 → "说不上是累还是有点烦"（22%）、空 → "提不起劲"（14%）。
  确定性哈希，不用 `Math.random`，测试才稳。
- 体感块的顺序：**先说"他来了"，再说身体**。反过来时模型会抓着"缺觉/发钝"不放。

### 5. 精神层 `psyche.mjs`

- 防御机制：幽默 / 升华 / 利他 / 压抑 / 合理化 / 回避（Vaillant 分级，规则选择而非打分）。
- 硬问题（必须重写）：`dodge`、`scold`、`time_prefix`、`meta_leak`、`repeat_question`、
  以及"当轮他给了具体事"时的 `self_absorption`、推给明天的 `defer`。
- `SOCIAL_CONTRACT`：可以累/烦/话短，但必须先接住内容；不许把"我困/我在忙"当主体；不许反问"你到底想让我干嘛"。

### 6. 表达层 `expression.mjs`

- `stripTimePrefix` 反复剥多层标注（`[19 分钟前] [刚刚] …`）。
- `sanitize` 额外剥说话人标签与连续空行；不碰 `[[情绪]]` / `[表情:标签]`。
- `shapeBlock` 按言语行为给结构（EMOTE：接语气，别追问；REPAIR：表明听懂新版本）。

## 四、接线（qq-server 四处）

| 时机 | 调用 | 作用 |
|---|---|---|
| 记忆落盘后 | `perceiveLogged` | 解码 + 线程推进 + 调质脉冲（一次写） |
| 装配前 | `buildMessages({ cohere })` | 决定是否注入"上次断在哪"；【此刻】剥掉负面状态 |
| 体感之后 | `applyFrame` | 追加 ≤900 字的 5 层提示块；微调温度（±0.06）与预算（×0.55–1.15） |
| 出稿后 | `gateAndRewrite` | 清洗 + 复核；硬问题重写一次（不阻塞发送） |

## 六、顺带修掉的隐私泄露（同一次实测发现）

| 位置 | 病 | 修 |
|---|---|---|
| `persona.ledgerBlock` | 账本块对所有 QQ 私聊注入 —— 任何加了她的网友问一句"余额多少"，她会报出真实余额与日花费（实测内省已经在说"我凭什么给你看啊"，但块就在 system 里） | 只对 `owner.qq` 本人注入；`userId` 缺失也不注入 |
| `brain/recall.bundle` | `audience='private'` 一律放行 → 陌生人上下文里出现主人私聊原话 | 新增 `stranger`（只给 `scope='public'`）；`isOwner` 显式 false 才降级 |
| `persona` 的段索引 / `recallAll` / `recall`+`randomOld` | 都是跨会话数据；陌生人能在【你们之前聊过】里读到主人对话标题 | 非本人私聊：段索引按 `chat` 过滤、跳过 `recallAll`、跳过按内容检索与随机旧事 |

一个必须记住的边界：`owner.qq` **未配置**时回退旧行为（private），否则新装机第一条消息就没有记忆 —— "没配 owner"不等于"所有人都是陌生人"。

## 七、性能与竞态（第二轮"根治"）

第一次修完"内容"后，实测仍有三个**时间维度**的断裂，都不是提示词能解决的：

| 病 | 证据 | 修 |
|---|---|---|
| 连发时用旧语境答话 | 两条间隔 2.5 秒：第一条停顿 3 秒后仍继续生成，第二条要等它 38 秒后才开始 | `inbound-seq`：**入队时**领号（不是 handle 开始时——串行队列下永远看不到积压），停顿后/生成后各检查一次，旧的那条让位（实测日志 `⏭ 让位`） |
| 工具链无总预算 | `TOOL_TIMEOUT_MS = 130000`：一次回复最坏 4×130 秒；实测两个工具失败就拖到 38 秒 | 三层预算：整条 30s / 单轮 20s / 单工具 12s，超了带已有结果收尾 |
| 工具清单撒谎 | 容器里没有 chromium，但 `browse_page` 一直在清单里 → 每轮先崩一次 `spawn chromium ENOENT`，白烧 8~15 秒 | `CHAT_TOOLS` 按真实能力过滤（清单即承诺）；网络搜索保留 `look_up`（curl 回落可用） |

同一轮还修了：
- `brain.mode=live` 的装配补齐时间维度与历史清洗 —— 两条路线行为一致，切模式不会"换一个人"。
- 重写一次仍不通过 → `psyche.scrub` 按句删违规句（全删光给最小接住句）。**提示词管概率，闸门管结果。**
- 群聊线程不背私聊任务，block 里的"他"在群里换成"对方"（群友 ≠ 主人）。

实测（22:48）：「帮我查一下今天B站的热榜」从请求到发出 **4.3 秒**（同一路径旧版 38 秒）。
